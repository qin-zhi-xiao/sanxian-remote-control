# 快传

手机接管电脑终端与智能体（微信小程序竞赛项目）。

## 快速开始

1. 电脑端双击 `dist\启动快传.bat`（或运行 `dist\kuaichuan.exe --gw <网关地址> --code 886613`）
2. 手机微信扫码打开小程序
3. 首次打开填配对码 → 测试连接 → 进入欢迎页

## 目录

| 目录 | 内容 |
|---|---|
| `src/` | 小程序源码 |
| `pc/` | 电脑端 Rust 源码 |
| `cloud/` | 两个云函数 |
| `dist/` | 可执行文件与启动脚本 |
| `docs/` | **项目报告、需求方案、开发记录** |
| `tools/` | 推送、CDP 自动化脚本 |

## 从哪读起

- 想知道这个项目做了什么、做到什么程度 → `docs/项目报告.md`
