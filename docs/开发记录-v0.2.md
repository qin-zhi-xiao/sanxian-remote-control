### 3. 模拟电脑（选项 C 的核心）
`utils/relay.js` 里默认开启模拟模式：

- 发送指令 → 立即入队（`pending`）→ 400ms 后 `running` → 约 1～1.7s 后 `done`
- 内置假输出：`whoami`、`ls`、`dir`、`echo x`、`git xxx`、`node -v`，其它命令给「这是模拟输出」的提示
- `agent` 类型返回预置回复，`app` 类型返回「已唤起 XXX」
- 历史存本地 storage，最多 50 条
- 关掉模拟开关 → 走 `sendReal()`，写 `commands` 集合并轮询结果（**这条没验证**，见第四节）

### 踩过的坑（都记下来，下次别再踩）
1. **Monaco 会自动补全括号** —— 用 `Input.insertText` 灌整份文件，JSON 会多出 `}`。改成**写剪贴板 + Ctrl+V 粘贴**。
2. **焦点必须给编辑器的隐藏 textarea**：`document.querySelector('.monaco-editor textarea.inputarea').focus()`，点坐标不可靠（一有弹窗就点到页面上，Ctrl+A 会把整页文本复制走）。
3. **弹窗会挡住一切点击**：`.common-dialog-overlay`；「请输入目录名」和「请输入文件名」是两个不同 placeholder，`确定` 按钮要在 `.common-dialog-container` 里找。
4. **文件树行的 innerText 包含子节点文本**，判定节点要取「第一行等于名字 且 文本最短」的那个。
5. **折叠的文件夹不会渲染子行**，要 `folderState()` 看 `.arrow-span[data-open]` 先展开。
6. **模拟器是跨进程 iframe**，CDP 的合成鼠标/触摸事件进不去 → 用**系统级鼠标事件**（SetCursorPos + mouse_event），并且要给窗口一个不在屏幕外的位置。
7. **平台只认 Chrome UA**，Edge 会被打回 `/upgrade`；自动化实例用 `--user-agent="Mozilla/5.0 ... Chrome/156 ..."` 启动（参数里的空格要引号包住，否则 UA 会被截断成 `Mozilla/5.0`）。
8. **登录态是会话级 Cookie**，浏览器一重启就掉，登录一次之后不要再重启。
